# Agent rules

- The project description belongs in `README.md`, not in this file.
- Manage dependencies with uv only: add a new library with `uv add <package>` (or `uv add --dev <package>` for dev tools). Never use `pip install` or edit `pyproject.toml` by hand.
- Write all code comments, docstrings, markdown cells, and other written content in English.
